## Required Global Corrections

1. Mark every output and file package **DRAFT / NOT APPROVED FOR PUBLICATION**.
2. Replace any claim equivalent to `לקוחות הנכונים`, `כולם`, `יש פתוח`, `כאן הכל`, or dense map pin coverage with factual launch-stage language.
3. Confirm launch geography before using `תל אביב`; otherwise use `אזור ההשקה הראשון`.
4. Confirm rights/source evidence for every photo-like storefront, person, food, flower, jewelry, or street scene. If rights are not documented, use owned/generated illustrative assets with no fake business identity.
5. Reduce visual text density for Meta safe zones: one headline, optional 1-line support, logo/domain, and CTA only. Move explanations into Primary Text.
6. Convert current 941×1672 assets into required delivery specs before approval. They are near 9:16 but not exact 1080×1920, and feed versions need a deliberate 1080×1350 or 1080×1080 layout.
7. Do not use screenshots or pin clusters that imply the marketplace already contains live listings unless source data and publication permission are documented.

## Creative QA Notes by Format

- Feed posters: use the owner-focused concepts first. The product need is clearer, and the platform can truthfully invite draft creation before the marketplace is full.
- Stories: keep consumer stories as launch teasers only. The current visuals feel like active marketplace ads, so they need launch caveats or abstracted map marks.
- Safe zones: keep important story text away from the top/bottom UI bands. Current compositions place brand/text close enough to edges that final 1080×1920 exports need preview QA.
- Grammar/RTL: Hebrew direction and register are generally natural. Main copy risk is not grammar; it is factual overclaiming and too much small supporting text.
- Brand: `פה קרוב` is used correctly. Avoid treating `Pokarov` as visible consumer branding except in the domain.
