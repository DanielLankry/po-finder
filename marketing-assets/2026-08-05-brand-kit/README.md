# חבילת Brand Kit וצילומי מוצר — פה קרוב

עודכן: 05.08.2026
אתר מקור: https://pokarov.co.il

## החלטת מותג

השם היחיד להצגה הוא **פה קרוב**. `pokarov.co.il` מיועד לדומיין, אימיילים וקישורים טכניים.

## מבנה התיקייה

- `01-logos/` — SVG ראשי, PNG שקוף 2400px, גרסאות לרקע בהיר/כהה ואייקונים.
- `02-brand-guide/` — צבעים HEX/RGB, Brand DNA, naming והנחיות שימוש.
- `03-fonts/` — קובצי Assistant ו־Karantina, CSS וקישורי רישיון.
- `04-product-screenshots/01-live-public/` — צילומי פרודקשן אמיתיים ברזולוציות המבוקשות.
- `04-product-screenshots/02-requires-real-business-data/` — רשימת המסכים שאי אפשר להפיק בכנות עד שיהיו עסקים וחשבון בעלים לצילום.
- `05-ad-creatives/` — 11 קובצי קריאייטיב מקוריים: מודעות השקה, סטוריז ומדריך מותג חזותי.
- `source/` — סקריפטים שחוזרים ובונים את הלוגואים ומצלמים מחדש את האתר החי.
