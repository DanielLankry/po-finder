# צילומי פרודקשן ציבוריים

כל הקבצים בתיקייה זו צולמו מהאתר החי `https://pokarov.co.il` ב־05.08.2026.

- צילומי המובייל נוצרו ב־360×640 CSS pixels עם device scale factor 4, ולכן הקובץ הסופי הוא 1440×2560 אמיתי ולא הגדלה של צילום קטן.
- צילום הדסקטופ הוא 1440×900.
- האתר החי מציג כרגע אפס עסקים. לכן צילומי המפה והרשימה משקפים מצב השקה ריק ואינם כוללים פינים או כרטיסים מומצאים.
- מסכי המיקום/קטגוריה ושעות הפעילות צולמו כמסכים נפרדים כי במוצר הנוכחי מיקום וקטגוריה נמצאים בסרגל העליון, ו„פתוח עכשיו” נמצא במגירת הסינון המתקדם.
