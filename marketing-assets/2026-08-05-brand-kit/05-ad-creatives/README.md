# קריאייטיבים לפרסום — פה קרוב

בתיקייה זו נשמרים 11 קובצי PNG מקוריים, ללא שינוי בשם, במידות או בתוכן.

## מבנה

- `01-platform-launch/` — שלוש גרסאות של מודעת השקת הפלטפורמה.
- `02-stories/` — שבע מודעות סטורי לעסקים, אוכל ויוצרים מקומיים.
- `03-brand-reference/` — לוח השראה ומערכת עיצוב חזותית.

השמות בעברית נשמרו כדי להקל על איתור הקריאייטיב לפי הקמפיין והתוכן.
