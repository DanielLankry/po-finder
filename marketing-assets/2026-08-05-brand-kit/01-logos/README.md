# לוגואים ואייקונים

## קבצים לשימוש

- `pokarov-logo-main.svg` — לוגו ראשי על רקע שקוף.
- `pokarov-logo-main-transparent-2400x700.png` — PNG שקוף ברוחב 2400px.
- `pokarov-logo-for-light-background.*` — דיו ירוק כהה לרקע בהיר.
- `pokarov-logo-for-dark-background.*` — טקסט לבן־חם לרקע כהה.
- `pokarov-icon-official.svg` — אייקון ללא טקסט באריזת SVG עצמאית.
- `pokarov-icon-official-512.png` — האייקון הרשמי הקיים באתר.
- `pokarov-icon-official-transparent-2048.png` — גרסת PNG שקופה 2048×2048.
- `pokarov-app-icon-512.png`, `pokarov-app-icon-192.png`, `favicon.ico` — אייקוני האתר הקיימים.

## הערת מקור חשובה

האייקון הרשמי קיים בריפו כ־PNG, לא כמאסטר וקטורי. קובצי ה־SVG בחבילה משתמשים באייקון הרשמי כשהוא מוטמע בתוך SVG, ובטקסט חי בפונט Karantina. הם עצמאיים ונוחים למסירה, אך האיור של הדוכנים אינו וקטור עריך. אין להציג אותו כציור וקטורי מקורי.

הגרסאות לרקע בהיר וכהה נוצרו מהאייקון הרשמי ומהחלטת השם המאושרת; לא נמצאה בריפו מערכת לוגואים קודמת עם וריאציות מאושרות נפרדות.
